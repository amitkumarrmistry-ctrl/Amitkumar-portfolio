# Amitkumar Mistry — Data Engineering Portfolio

A modern dark-theme personal portfolio built with Next.js, TypeScript, and custom CSS. Designed to position Amitkumar for senior data engineering opportunities focused on Databricks and Snowflake.

## Run locally

Requirements: Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before publishing

1. Add your GitHub profile URL in `app/page.tsx` and replace each project link with the matching repository.
2. Replace `hello@example.com` with a public contact email.
3. Add your final resume PDF to `public/` and add a resume link in the navigation or contact area.
4. Verify all skills, certification names, experience details, and metrics. Remove anything you cannot comfortably discuss in an interview.
5. Replace `https://example.com` in `app/layout.tsx` with your final domain.
6. Keep client names, client data, proprietary code, and confidential architecture out of public repositories. Use synthetic datasets and recreated examples.

## Deploy to Vercel

1. Create a GitHub repository and push this project.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository. Vercel should detect Next.js automatically.
4. Keep the default build settings and select **Deploy**.
5. Add your custom domain in the Vercel project settings when ready.

## Project showcase status

The six project cards are intentionally marked **Build this project**. They are project briefs, not claims that the implementations are complete. Update the status and links only after each repository is ready.

## Customize

- Main page and project content: `app/page.tsx`
- Design system and responsive styles: `app/globals.css`
- SEO metadata: `app/layout.tsx`
